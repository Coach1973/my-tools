# 大樹的常用查詢網站（個人專用）

網址：https://coach1973.github.io/my-tools/

- 資料在 `tools.json`，頁面由 `build.py` 產生 `index.html`（改 `build.py` 內 `S` 清單後重跑 `python build.py`）。
- 新網址丟給 AI，會補進對應分類。
- 刪除（網址或整個分類）都不會直接消失：先放到最下面的「🗑 已刪除」（上方按鈕也能跳過去），比照「大樹作品一覽」的「最近刪除」：可按「↩ 復原」或用「☑️ 批量搬移模式」勾選後搬回任一分類；確定不要了才「🗑 永久刪除」單筆或「永久清空」。資料存在 `trash`（已刪除）與 `purged`（永久刪除的原始清單網址）欄位；舊版只記網址的刪除紀錄，載入時會自動補成可復原的項目。
