# 大樹的常用查詢網站（個人專用）

網址：https://coach1973.github.io/my-tools/

- 資料在 `tools.json`，頁面由 `build.py` 產生 `index.html`（改 `build.py` 內 `S` 清單後重跑 `python build.py`）。
- 新網址丟給 AI，會補進對應分類。
- 刪除的網址不會消失：先放到最下面的「🗑 已刪除」（上方按鈕也能跳過去），按「↩ 復原」放回原本分類。資料存在 `trash` 欄位；舊版只記網址的刪除紀錄，載入時會自動補成可復原的項目。

## 「比照大樹作品一覽」＝一模一樣的定義與驗收表

（2026-10-21 軍師整理。教練 10/15 起一直說「要跟大樹作品一覽一樣」，沒人定義過什麼叫一樣，每次只做教練剛抱怨的那一項，11 次修改都是這樣來的。以後改這個網站，先對照這張表。）

**以大樹作品一覽（`Coach1973/coach888` 的 `index.html`）為標準答案，這五件事都要一樣：**
1. **功能一樣**：作品一覽有的每一項功能，這裡都要有，一項不少（包含教練沒一項項講過的）。
2. **操作一樣**：同一個動作用同一種方式做。作品一覽是「點文字直接改」「抓 ⠿ 拖曳」「按 ✕ 刪除」，這裡不能改成按鈕加彈窗或 ▲▼。
3. **名字一樣**：按鈕和區塊叫同樣的名字（最近刪除、批量搬移模式、熱門排行、複製目前排序）。
4. **規則一樣**：刪除項目不跳確認、直接進最近刪除；永久刪除、永久清空、刪整個分類要確認；改完自動存、各裝置同步。
5. **一次交整份**：附這張表，每一項在真瀏覽器操作過才算交付，不是做一部分再等教練提醒。

不要求一樣的：網址資料本身（這頁放常用查詢、那頁放作品）、配色與版面。作品一覽之後新增功能，這張表重核一次，這頁跟著補。
