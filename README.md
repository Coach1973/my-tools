# 大樹的常用查詢網站（個人專用）

網址：https://coach1973.github.io/my-tools/

- 資料在 `tools.json`，頁面由 `build.py` 產生 `index.html`（改 `build.py` 內 `S` 清單後重跑 `python build.py`）。
- 新網址丟給 AI，會補進對應分類。
- 刪除的網址不會消失：先放到最下面的「🗑 已刪除」（上方按鈕也能跳過去），按「↩ 復原」放回原本分類。資料存在 `trash` 欄位；舊版只記網址的刪除紀錄，載入時會自動補成可復原的項目。

## 「比照大樹作品一覽」＝一模一樣＝照抄

（2026-10-21 軍師整理。教練 10/15 起一直說「要跟大樹作品一覽一模一樣」。一模一樣就是百分之百照抄，只有教練明說的地方才不一樣；這裡教練明說的只有「放的是常用查詢網址」。11 次修改的原因：每個 AI 都沒有照抄作品一覽，而是自己另寫一套，再一項一項補教練抱怨的地方。）

**做法**：以作品一覽（`Coach1973/coach888` 的 `index.html`）的程式為底照抄，只換掉裡面的資料。以後改這個網站，先對照下面這張表；作品一覽多了功能，這裡跟著照抄。
